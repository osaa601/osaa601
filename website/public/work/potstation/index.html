GRADUATION PROJECT

PotStation

A honeypot-platform graduation project exploring deployment, visibility, and threat observation.

HoneypotsLinuxDocker

Academic project · 2024–2025

Overview

PotStation explored a service-based approach to deploying and working with honeypots. The project connected security experimentation with infrastructure and platform design, using T-Pot CE and a supporting application stack.

Areas of work

  • Honeypot deployment and operational architecture.
  • Linux and container-based infrastructure.
  • Threat observation and security visibility.
  • Documenting the project design and graduation work.
Current stage

Presented as an academic project, not as a publicly available commercial service. The project stack included T-Pot CE, Ubuntu, Docker, Spring, MySQL, Node, and Nginx.
